# understand-skill

特德·姜在《人类科学之演变》（*The Evolution of Human Science*）中设想了一种处境：知识仍在飞速向前发展，最前沿的成果却逐渐超出普通人类科学家能够直接理解的范围。人类科学家的工作因而发生变化。他们开始解释那些成果，把它们重新放回人类已有的概念、经验与问题之中，使人们知道其中说了什么、为什么值得在意，以及它将怎样改变我们对世界的认识。

大语言模型的发展让这个图景显得越来越近。新的模型、证明、程序与实验，也许会越来越多地依赖高度密集的信息表示和人类难以逐步跟随的推演。LLM 可能参与产生这些成果，也可能成为人类理解它们的中介。后一项工作远不止摘要：它需要重新安排人能够跟随的讲述顺序，补充机器表示中省略的联系，把结论带回可以追问、怀疑、比较和使用的知识世界。原文、代码、实验与事实构成这项阐释的依据，由此形成的理解应当经得起继续核对和判断。

`understand-skill` 从今天已经出现的情形着手。面对一篇论文、一段代码、一部作品、一个议题或任何陌生对象，它要求 LLM 留意用户此刻已经明白什么、正在追究什么，以及下一层理解需要依靠哪些联系。术语、例子、资料与细节按照实际需要出现；讲述随着用户的复述、困惑和追问改变方向。它把重点放在讲述者的判断上，根据每个对象本身的关系安排理解顺序。

这项工作的目标，是让人继续参与知识。即使一段推演无法由人亲自走完，人仍应当有机会理解它与什么有关，形成自己的判断，并决定怎样使用它。今天，这表现为一次自然、清楚的学习对话；未来，它或许会成为人类继续拥有科学的一种方式。

## 安装

将仓库放入 Codex 的 skills 目录：

```bash
git clone https://github.com/dicaeopolis/understand-skill.git "${CODEX_HOME:-$HOME/.codex}/skills/understand-skill"
```

Windows PowerShell：

```powershell
git clone https://github.com/dicaeopolis/understand-skill.git "$env:USERPROFILE\.codex\skills\understand-skill"
```

安装完成后开启新的 Codex 对话，即可直接提出学习请求，也可以明确调用：

```text
使用 $understand-skill，我想了解……
```
