# understand-skill

特德·姜在《人类科学之演变》（*The Evolution of Human Science*）中设想过这样一种未来：科学仍在飞速发展，最前沿的成果却逐渐超出人类科学家能够直接理解的范围。人类科学家的工作也随之改变。他们开始向人们解释这些成果，用已有的概念和经验说明其中的内容，回答它们与我们关心的问题有什么关系、为什么值得在意，以及会怎样改变我们对世界的认识。

大语言模型的迅速发展，让这个图景离我们越来越近。未来的科学成果，也许会越来越多地以高度压缩、难以由人直接阅读的信息形式产生，其中的推演也可能复杂到人无法逐步跟随。LLM 既可能参与产生这些成果，也可能帮助人理解它们。

要完成后一项工作，LLM 需要按照人能够理解的先后顺序重新讲述，把压缩表达中省去的联系补充出来，使人能够围绕结论继续追问、质疑、比较和使用。这种阐释始终以原文、代码、实验和事实为依据，读者可以据此继续核对，并形成自己的判断。

这样的需要今天已经出现。面对一篇论文、一段代码、一部作品、一个议题或其他陌生对象，`understand-skill` 要求 LLM 留意用户已经明白什么、正在追究什么，并判断还要讲清哪些联系，用户才能继续理解。讲述者只在需要时引入术语、例子、资料和细节；用户复述自己的理解、提出困惑或继续追问以后，后续讲解也随之调整。不同对象各有自己的脉络，讲述顺序应当由这种脉络和用户当前的理解共同决定。

这项工作的目标，是让人继续参与知识的理解、判断和使用。即使人无法亲自完成整个推演，仍然可以理解它在回答什么问题，形成自己的判断，并决定怎样使用它。眼下，我们从一次自然、清楚的学习对话开始；未来，它或许会成为人类继续拥有科学的一种方式。

## 安装

将仓库放入 Codex 的 skills 目录：

```bash
git clone https://github.com/dicaeopolis/understand-skill.git "${CODEX_HOME:-$HOME/.codex}/skills/understand-skill"
```

Windows PowerShell：

```powershell
git clone https://github.com/dicaeopolis/understand-skill.git "$env:USERPROFILE\.codex\skills\understand-skill"
```

安装完成后开启新的 Codex 对话，即可直接提出学习请求，也可以明确调用：

```text
使用 $understand-skill，我想了解……
```
